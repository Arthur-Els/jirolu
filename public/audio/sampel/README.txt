Folder ini disediakan untuk file audio contoh permainan lagu instrumen gamelan.

Format nama file yang didukung:
- saron-lagu.mp3
- bonang-lagu.mp3
- gong-lagu.mp3
- kendang-lagu.mp3

Kamu bisa meletakkan file audio lagu (.mp3 atau .webm) di folder ini, dan tombol "Dengarkan Contoh Lagu" di Galeri Pameran akan otomatis memutarnya!
